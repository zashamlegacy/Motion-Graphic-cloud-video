# Moodboard Style: Motion Graphic / Infographic Berengagement Tinggi
Tarikh riset: 14 Okt 2026. Sumber: artikel web + data Facebook Reels. Nota: TikTok & FB tak boleh dibrowse terus (login/blok), jadi bahagian "trending" datang dari artikel, bukan scroll feed sebenar. Angka dari blog vendor = indikatif, bukan hukum.

## A. 6 Style Yang Terbukti (ranking untuk niche edu/kewangan/self-improvement, 9:16)

1. **Stick-figure + kertas krim (faceless)** — paling dekat dengan reel 1714081337389666 & 1DLwP1y2tL kau.
   - Watak minimal, konsisten setiap scene, emosi lewat pose (facepalm, lari, celebrate, pegang prop).
   - Tiada background rumit → perhatian kekal pada skrip & punchline.
   - Satu baris skrip = satu frame (beat-by-beat).
   - Niche sesuai: personal finance, relationship, workplace satire.
   - Palet cadangan (ukur dari reel kau): kertas #F2EDDF, hitam #000, aksen merah #E62424.
2. **Paper-cutout / torn-paper / cutting-mat (Reel A "AI Terbaru")** — tekstur tactile, label kuning/putih koyak, post-it, slam text. Sesuai berita/tips pantas.
3. **Kinetic typography (teks sebagai visual)** — tulisan besar beranimasi, sync dengan sound design; satu perkataan aksen berwarna.
4. **Hand-drawn / imperfect** — garisan kasar, tekstur sketch; rasa "manusia", mudah dipercayai.
5. **Minimal motion** — palet terhad, animasi halus, kebolehbacaan dulu.
6. **Mixed media / collage** — campur 2D + foto + overlay untuk lari dari rupa "terlalu AI/polished".

Nota: 3D sinematik & AR bagus untuk produk, tapi bukan untuk explainer — kos tinggi, retention tak lebih.

## B. Peraturan Retention (Facebook/IG/TikTok Reels)

| Perkara | Peraturan | Sumber |
|---|---|---|
| Panjang | 15–30s sweet spot; tutorial 30–45s; kebanyakan top <45s | OpusClip |
| Hook | Janji/curiosity dalam 3s pertama | OpusClip |

| Rentak | Beat baru setiap 3–5s; buang jeda >0.5s; ~2.5–3 patah/saat | OpusClip |
| Format | 9:16 menang besar: reach +20.9%, retention 30s +38.5% | Emplifi |
| Loop | Video ≤7s dengan loop mulus: replay +18.7%, reach +23.6% | Emplifi |
| Teks | Overlay tambah retention 3s/10s, TAPI untuk video speech-driven kurang 10s retention -6% → guna teks ringkas (headline + kata kunci), bukan ayat penuh | Emplifi |
| Caption | >80% tonton senyap (tak bersumber) — tetap letak caption kontras tinggi di 2/3 atas frame | OpusClip |

| Ujian | Test 15/30/45s, banding selepas 48 jam, tengok graf drop-off | OpusClip |

Sasaran: retention purata ≥70% (baik), ≥80% (cemerlang).

## C. Resipi "Salin Style" (gabung semua)
- Canvas 1080×1920, 30fps, kertas krim #F2EDDF, tulisan hitam + SATU perkataan merah.
- Headline Anton ~100px, 2 baris, tengah; ilustrasi stick-figure di 2/3 bawah.
- Hard cut + jeda kertas kosong 0.2s ikut senyap VO; ikon "pop" tepat pada perkataan disebut.
- Hook 3s: VO bermula frame pertama, headline serta-merta, tiada intro/logo.
- Pacing: perubahan visual setiap 1.5–3s (reel kau sebenarnya lebih laju daripada 3–5s — ini sebab ia rasa "padat").
- Tamat dengan CTA pendek atau ayat yang boleh loop ke hook.
